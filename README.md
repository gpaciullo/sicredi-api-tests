# Sicredi API Automation Framework

## Overview

This project is a scalable API test automation framework developed using Java, RestAssured, TestNG, and Maven, designed to validate high-volume transactional and distributed systems through automated API testing strategies.

The framework demonstrates advanced software quality engineering practices focused on system reliability, automated validation, and operational risk mitigation in enterprise-grade environments.

---

## Objectives

The primary objectives of this project include:

- Automated validation of RESTful APIs
- Early detection of integration failures and data inconsistencies
- Validation of response integrity and business rules
- Support for scalable and reusable testing strategies
- Reduction of operational risks through preventive quality engineering

---

## Technologies Used

- Java
- RestAssured
- TestNG
- Maven
- GitHub Actions
- JSON Schema Validation
- CI/CD Pipelines
